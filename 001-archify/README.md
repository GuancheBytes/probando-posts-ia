# 1/100 · Archify

**El post:** "Diagramas de arquitectura con IA que dan gusto enseñar". Visto en Instagram (midudev).
**Qué promete:** convierte tu proyecto en un HTML interactivo con modo claro/oscuro, animación y exportación a PNG, SVG o PDF. También dibuja flujos, estados y secuencias.
**Repo oficial:** [tt-a1i/archify](https://github.com/tt-a1i/archify) · Licencia Apache-2.0 · Funciona en Claude Code, Codex, OpenCode y Cursor.

## ✅ Pasos

### 1. Instala la skill
```bash
npx skills add tt-a1i/archify -g
```
Instalación manual en Claude Code: clona el repo y copia la carpeta `archify/` en `~/.claude/skills/`.

### 2. Reinicia tu agente
Cierra y vuelve a abrir Claude Code (o Cursor, Codex, OpenCode) para que cargue la skill.

### 3. Pídele el diagrama
Abre tu proyecto y escribe algo como:
```
Usa archify para crear un diagrama de arquitectura interactivo de este repositorio
```

### 4. Abre el HTML
Se genera un archivo HTML autocontenido. Ábrelo en el navegador y prueba el modo claro/oscuro, la animación y la exportación.
